Kinematic driver: cloud and precipitation with P3

This example uses PrescribedDynamics to lift moist air through a vertical column at 2 m/s. P3Microphysics predicts cloud droplets, rain, ice, and liquid water carried on ice, with a prognostic vapor excess over liquid and aerosol activation. Velocity is prescribed while transport, thermodynamics, and microphysics evolve. We use liquid–ice potential temperature, the default thermodynamic formulation, explicitly selected below for clarity.

This is an open column: moist air enters at the bottom, air leaves at the top, and hydrometeors can sediment out. The rising-parcel example instead retains all water in a closed moving parcel. This setup demonstrates the ingredients of a kinematic microphysics comparison; it is not a reproduction of the upstream P3 kin1d benchmark.

using Oceananigansusing Oceananigans.Unitsusing Breezeusing Breeze.Microphysics.PredictedParticleProperties: AerosolActivation, AerosolModeusing CairoMakieusing Printf

Grid and background atmosphere

The column extends through the troposphere into the lower stratosphere. We construct hydrostatic pressure and density using the same potential temperature profile used to initialize the model. The atmosphere starts at 80% relative humidity over liquid water, with no condensate.

Nz = 100Lz = 20kilometersgrid = RectilinearGrid(CPU(); size=Nz, z=(0, Lz), topology=(Flat, Flat, Bounded))constants = ThermodynamicConstants()θ₀ = 300p₀ = 1e5ℋ₀ = 0.8zᵗʳ = 12kilometersθᵗʳ = 343Tᵗʳ = 213g = constants.gravitational_accelerationcᵖᵈ = constants.dry_air.heat_capacityfunction θ_initial(z)    θ_troposphere = θ₀ + (θᵗʳ - θ₀) * (z / zᵗʳ)^(5/4)    θ_stratosphere = θᵗʳ * exp(g / (cᵖᵈ * Tᵗʳ) * (z - zᵗʳ))    return ifelse(z ≤ zᵗʳ, θ_troposphere, θ_stratosphere)endreference_state = ReferenceState(grid, constants;                                 base_pressure = p₀,                                 potential_temperature = θ_initial)
ReferenceState{Float64}(p₀=100000.0, θ₀=300.0, pˢᵗ=100000.0)

Prescribed ascent and P3

Uniform vertical velocity does not satisfy ∂z(ρw) = 0 for a stratified density profile. divergence_correction=true compensates for that mass-flux divergence in the transported specific quantities. The flow remains prescribed even as latent heating changes the temperature.

P3's vapor_excess=PrognosticVaporExcess() adds ρδqᵛ⁺ˡ, the density-weighted vapor excess over liquid. Aerosol activation also predicts cloud droplet number and the remaining aerosol reservoir. Number mixing ratios are in kg⁻¹.

W₀ = 2nᵃ₀ = 3e8dynamics = PrescribedDynamics(reference_state; divergence_correction=true)aerosol = AerosolActivation(AerosolMode(number_mixing_ratio=nᵃ₀); prognostic=true)microphysics = P3Microphysics(; aerosol, vapor_excess=PrognosticVaporExcess())

Incoming air and precipitation boundaries

At the surface, pressure equals the standard potential-temperature reference pressure, so the condensate-free inflow has T = θ₀. Its moisture and vapor excess are calculated from the same relative humidity. Fresh aerosol enters with the air; all incoming hydrometeor mass and number are zero. P3's default open precipitation boundary allows sedimentation out of the column.

Initializing the vapor excess

First initialize the thermodynamic state. Then initialize the density-weighted vapor excess from that state, so the prognostic starts with the actual vapor deficit. This second set! depends on the temperature and moisture established by the first.

set!(model; θ=θ_initial, ℋ=ℋ₀, w=W₀)μ = model.microphysical_fieldsρ = reference_state.densityqᵛ⁺ˡ = SaturationSpecificHumidity(model)set!(model; ρδqᵛ⁺ˡ=ρ * (μ.qᵛ - qᵛ⁺ˡ))

Simulation and output

Run for 3600 s, saving profiles every 30 s. The output retains both the prognostic and diagnosed vapor excess, along with mass and number concentrations, for subsequent comparisons. The vapor excess δqᵛ⁺ˡ has units of kg/kg; it is not the dimensionless supersaturation 𝒮.

simulation = Simulation(model; Δt=1, stop_time=60minutes)Oceananigans.Diagnostics.erroring_NaNChecker!(simulation)diagnosed_δqᵛ⁺ˡ = Field(μ.qᵛ - qᵛ⁺ˡ)outputs = (; T = model.temperature,             μ.qᵛ, μ.qᶜˡ, μ.qʳ, μ.qⁱ, μ.qʷⁱ,             μ.nᶜˡ, μ.nʳ, μ.nⁱ, μ.nᵃ, μ.δqᵛ⁺ˡ, diagnosed_δqᵛ⁺ˡ)filename = "kinematic_driver_p3.jld2"simulation.output_writers[:profiles] = JLD2Writer(model, outputs;                                                 filename,                                                 schedule = TimeInterval(30),                                                 overwrite_files = true)function progress(sim)    μ = sim.model.microphysical_fields    @info @sprintf("t = %s, max cloud = %.2e, rain = %.2e, ice = %.2e kg/kg",                   prettytime(sim), maximum(μ.qᶜˡ), maximum(μ.qʳ), maximum(μ.qⁱ))    return nothingendadd_callback!(simulation, progress, TimeInterval(10minutes))run!(simulation)

Cloud and precipitation through time

Each panel shows the full time history of one condensate. Color scales are labeled separately because cloud, rain, ice, and liquid coating can have very different abundances. All mass fractions retain their model units of kg/kg. Figures are saved as high-resolution PNGs and zoomable SVGs.

qᶜˡts = FieldTimeSeries(filename, "qᶜˡ")qʳts = FieldTimeSeries(filename, "qʳ")qⁱts = FieldTimeSeries(filename, "qⁱ")qʷⁱts = FieldTimeSeries(filename, "qʷⁱ")Tts = FieldTimeSeries(filename, "T")qᵛts = FieldTimeSeries(filename, "qᵛ")δqᵛ⁺ˡts = FieldTimeSeries(filename, "δqᵛ⁺ˡ")diagnosed_δqᵛ⁺ˡts = FieldTimeSeries(filename, "diagnosed_δqᵛ⁺ˡ")

The time series is indexed over the physical column cells, excluding halos.

Temperature, vapor, and vapor excess

The two vapor-excess panels share a symmetric logarithmic color scale, linear within ±10⁻⁵ kg/kg. This resolves small vapor excesses and larger deficits on the same scale. The prognostic and diagnosed values can differ while transport, cooling, and microphysical relaxation act.

Unlike a closed parcel, the column's water inventory changes through inflow, outflow, sedimentation, and the prescribed divergence correction. A quantitative comparison with another kinematic driver must match those terms as well as the sounding, velocity profile, P3 options, and numerical resolution.
